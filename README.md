# Курсовая работа: State Management System на ООП

## 🎯 Обзор проекта

## 🏗️ Архитектура

### State Management System
Система управления состоянием построена на следующих ООП-принципах:

1. **Action** - базовый класс для описания действий
2. **Reducer** - абстрактный класс для обработки действий
3. **Store** - централизованное хранилище состояния (Singleton)
4. **Subscriber** - интерфейс для подписчиков на изменения

### Поток данных
```
UI → Action → Store → Reducer → New State → Subscribers → UI
```

### Ключевые принципы
- **Инкапсуляция** - каждый компонент имеет чёткую ответственность
- **Иммутабельность** - состояние никогда не изменяется напрямую
- **Однонаправленный поток данных** - предсказуемость изменений
- **Разделение ответственности** - UI, бизнес-логика и состояние разделены

## 📚 Документация

### Структура State Management
```typescript
// Базовый класс Action
class Action {
  constructor(
    public readonly type: string,
    public readonly payload?: any
  ) {}
}

// Абстрактный класс Reducer
abstract class Reducer<T> {
  abstract reduce(state: T, action: Action): T;
}

// Класс Store (Singleton)
class Store<T> {
  private static instance: Store<any> | null = null;
  private state: T;
  private subscribers: Subscriber<T>[] = [];
  private reducer: Reducer<T>;

  // ... методы управления состоянием
}
```
