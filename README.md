# State Management Lab

Интерактивное веб-приложение на React и TypeScript, демонстрирующее собственную систему управления состоянием на основе объектно-ориентированного подхода.

Проект объединяет:
- пользовательский интерфейс с несколькими экранами;
- собственный `Store`, `Action` и `Reducer`;
- демонстрационные сценарии для счётчика и списка задач;
- разделы с теорией, архитектурой и roadmap развития.

## Возможности

- Собственная реализация слоя state management без внешних библиотек.
- Единый store с подписками и обновлением интерфейса через `useSyncExternalStore`.
- Экран счётчика с историей изменений, шагом и undo.
- Экран задач с фильтрацией, поиском, сортировкой и приоритетами.
- Отдельные страницы с объяснением архитектуры и направлений развития.
- Адаптивный интерфейс с единой визуальной системой.

## Архитектура

В основе приложения лежит собственная схема управления состоянием:

```text
UI -> Action -> Store -> Reducer -> New State -> Subscribers -> UI
```

### Основные сущности

- `Action` описывает событие, которое должно изменить состояние.
- `Reducer` принимает текущее состояние и action, затем возвращает новую версию состояния.
- `Store` хранит данные, выполняет `dispatch` и уведомляет подписчиков.
- `useAppStore` связывает React-компоненты с store.

### Принципы

- Иммутабельные обновления состояния.
- Однонаправленный поток данных.
- Разделение UI и бизнес-логики.
- Расширяемость за счёт независимых state-модулей.

## Разделы приложения

### Главная

Краткий обзор системы, ключевые возможности и навигация по основным разделам.

### Счётчик

Демонстрирует базовое состояние и операции над ним:
- изменение значения;
- настройка шага;
- история изменений;
- undo;
- базовые метрики состояния.

### Задачи

Показывает работу с коллекцией объектов:
- добавление задач;
- удаление задач;
- переключение статуса;
- фильтрация;
- поиск;
- сортировка;
- управление приоритетом.

### Теория

Объясняет, как устроен state management и зачем нужен отдельный слой управления состоянием.

### Архитектура

Описывает структуру проекта, роль каждого слоя и связь между UI и store.

### Roadmap

Содержит направления дальнейшего развития и идеи для новых возможностей.
